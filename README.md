# Asclepius - Klasifikasi Kanker Kulit (Versi Indonesia)

## Ikhtisar
**Asclepius** adalah aplikasi Android yang dirancang untuk membantu pengguna dalam mengklasifikasikan penyakit kanker kulit menggunakan teknologi **Machine Learning**. Dibangun dengan bahasa pemrograman **Kotlin**, aplikasi ini memungkinkan pengguna untuk mengunggah gambar kulit dan mendapatkan prediksi klasifikasi kanker kulit secara instan. Selain itu, aplikasi ini juga menyediakan fitur untuk menyimpan riwayat klasifikasi dan menampilkan informasi terkini tentang penyakit kanker dari **Indonesia Health News API**.

## Fitur Utama
- **Klasifikasi Gambar**: Unggah gambar kulit dan dapatkan prediksi klasifikasi kanker kulit menggunakan model Machine Learning.
- **Riwayat Klasifikasi**: Simpan dan lihat riwayat hasil klasifikasi untuk referensi di masa mendatang.
- **Informasi Kanker Terkini**: Akses artikel dan berita terbaru tentang penyakit kanker dari **Indonesia Health News API**.
- **Mendukung Android SDK 21 (Android 5.0 Lollipop) ke atas**: Kompatibel dengan berbagai perangkat Android.

## Teknologi yang Digunakan
- **Kotlin**: Bahasa pemrograman utama yang digunakan untuk pengembangan.
- **Machine Learning**: Model ML untuk klasifikasi gambar kanker kulit.
- **Indonesia Health News API**: Sumber informasi terkini tentang penyakit kanker.
- **Android SDK 21**: Versi Android minimum yang didukung (Android 5.0 Lollipop).

# Asclepius - Skin Cancer Classification (English Version)

## Overview
**Asclepius** is an Android application designed to help users classify skin cancer using **Machine Learning** technology. Built with the **Kotlin** programming language, this app allows users to upload skin images and get instant skin cancer classification predictions. Additionally, the app provides features to save classification history and display up-to-date information about cancer from the **Indonesia Health News API**.

## Key Features
- **Image Classification**: Upload skin images and receive skin cancer classification predictions using a Machine Learning model.
- **Classification History**: Save and view classification history for future reference.
- **Latest Cancer Information**: Access articles and news about cancer from the **Indonesia Health News API**.
- **Supports Android SDK 21 (Android 5.0 Lollipop) and above**: Compatible with a wide range of Android devices.

## Technologies Used
- **Kotlin**: The primary programming language used for development.
- **Machine Learning**: ML model for skin cancer image classification.
- **Indonesia Health News API**: Source of up-to-date information about cancer.
- **Android SDK 21**: The minimum supported Android version (Android 5.0 Lollipop).
